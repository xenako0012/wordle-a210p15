# React: saludos y contador

Aplicación pequeña con React y Vite. `App.jsx` muestra saludos reutilizando
propiedades y un contador interactivo que conserva su valor con `useState`.

## Comandos

```bash
npm install
npm run dev
npm run build
npm run lint
```

La entrada de React está en `src/main.jsx`; la interfaz está en `src/App.jsx` y
los estilos globales en `src/index.css`.
